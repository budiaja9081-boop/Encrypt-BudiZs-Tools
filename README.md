ENCRYPT BUDIZS

Python source-code protection tool using AES-256-GCM.

Installation

1. Install requirements

pkg update
pkg install git python -y

2. Clone repository

git clone https://github.com/budiaja9081-boop/Encrypt-BudiZs-Tools.git

3. Enter project directory

cd Encrypt-BudiZs-Tools

4. Install dependencies

python -m pip install -r requirements.txt

5. Run the tool

python main.py
